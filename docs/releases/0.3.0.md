# SWU Deck Builder 0.3.0 — Reliable desktop AI and safer releases

SWU Deck Builder 0.3.0 restores the AI Deck Assistant in packaged desktop builds, makes local AI startup safer on Windows, and introduces a gated cross-platform release process. Version 0.2.0 could display `ENOTDIR, not a directory` as soon as a user sent a message, preventing Codex or Claude from responding.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## What's new since 0.2.0

### Deck Assistant works in packaged apps

The desktop app now creates its generated AI catalog in the operating system's writable per-user application-data directory. Version 0.2.0 incorrectly tried to create that file inside Electron's read-only application archive, causing the `ENOTDIR` error before the selected AI provider could run.

This fix applies to the Windows, macOS, and Linux desktop packages. The hosted browser app was not affected.

### Safer Codex and Claude startup on Windows

Windows installations of Codex and Claude commonly expose `.cmd` command shims. The desktop app now launches those shims with escaped argument handling instead of Node.js shell mode. This removes the `DEP0190` deprecation warning and prevents command arguments from being interpreted as shell syntax.

### Releases are validated before publication

Desktop releases now use a tag-driven, gated GitHub Actions workflow. A release is published only when its tag matches the package manifests, matching release notes are present, unit tests and lint checks pass on Windows, macOS, and Linux, and every platform package builds successfully. Failed validation or packaging leaves no published release.

## Upgrading from 0.2.0

Desktop users who use the AI Deck Assistant should upgrade to 0.3.0. Install the new version over the existing application; there is no need to delete your local settings or reconfigure your AI provider.

Decks, desktop settings, and AI provider preferences remain in the per-user application-data directory and are preserved during the upgrade.

## Get 0.3.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU Deck Builder-0.3.0 Setup.exe`
- **macOS, Apple Silicon or Intel:** the universal `.dmg`; use the `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** the `.deb` package
- **Fedora or RHEL Linux x64:** the `.rpm` package

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.
- Codex and Claude integrations use the account authenticated in the selected CLI and may consume that account's subscription allowance.

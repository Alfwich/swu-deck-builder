# SWU Deck Builder 0.6.0 — A focused desktop workspace

SWU Deck Builder 0.6.0 refines the Electron app into a steadier, cleaner desktop workspace with anchored side panels, an unobstructed deck canvas, and more compact navigation.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## What's new since 0.5.0

### A stable three-column desktop layout

The Electron workspace now keeps the **Decks** panel on the left and the **Card library** and **Format legality** panels on the right anchored in place while the deck content scrolls independently in the center. Scrolling through a long deck no longer moves every panel together.

The center scrollbar is visually hidden while mouse-wheel, touchpad, and keyboard scrolling continue to work. The center deck area also no longer has its own rounded container, gradient, border, shadow, or blur. Deck content sits directly on the application background, leaving the two side rails as the primary visual containers.

This viewport-bound behavior applies to the normal three-column Electron layout. Narrow and responsive layouts retain document scrolling so stacked panels remain reachable.

### Better-integrated Electron chrome

The desktop header has been resized and aligned around the operating system's standard window controls. Navigation controls share the same horizontal centerline as minimize, maximize, and close, with enough clearance for the header divider to continue beneath the window-control area.

The document scrollbar now uses a narrow, rounded dark treatment instead of the browser default. Header group separators also have balanced spacing, preventing dividers from crowding adjacent buttons.

### Compact split-button navigation

Related top-menu actions now share pill-shaped controls with independently clickable sections:

- **DB** groups **Export** and **Import** into one backup control.
- **New Deck** and **Import deck** share one primary deck-creation control.
- **Copy TCGplayer list** retains its integrated **Missing only** section.

The shorter **DB** label saves horizontal space without reducing accessibility: toolbar and button labels continue to describe the database actions in full. Each section preserves its own loading, disabled, hover, focus, and keyboard behavior.

## Upgrading from 0.5.0

Install version 0.6.0 over the existing desktop application. Saved decks, the card collection, desktop AI settings, and provider preferences are preserved. This release does not change the player-database backup format.

## Get 0.6.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.6.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.6.0_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.6.0-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Database backup files remain on backup schema version 1 and are limited to 5 MB.
- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.
- Image attachments remain limited to the Codex provider in the Electron app.
- Codex and Claude integrations use the account authenticated in the selected CLI and may consume that account's subscription allowance.

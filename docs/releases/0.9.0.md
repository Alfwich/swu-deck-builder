# SWU Deck Builder 0.9.0 — Compact assistant layouts and roomier backups

SWU Deck Builder 0.9.0 adds dedicated Small and Large layouts for the AI Deck Assistant, remembers each user's preferred size, and raises the player-database backup import limit for unusually large collections.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.8.1

### Choose a Small or Large Deck Assistant

The Deck Assistant header now includes a segmented **Small / Large** size control. Large preserves the full conversation workspace introduced in earlier releases, while Small is a purpose-built desktop layout with a narrower panel, shorter transcript, denser messages, compact card-change proposals, and a reduced composer.

Small is designed for keeping the assistant open beside a deck without covering as much of the workspace, particularly in the Electron app or on displays using increased operating-system scaling. Both presets remain constrained to the available viewport, and the existing drag and keyboard resize controls continue to support custom heights.

### Remember the preferred assistant size

The selected Small or Large layout is now stored locally and restored when the application starts again. New Electron installations begin with Small because it is better suited to the desktop workspace; the hosted web app continues to begin with Large. Choosing either preset overrides that default on later launches.

Manually resizing the assistant switches it to the Large layout, preserving the existing flexible workspace behavior. Invalid or unavailable browser storage safely falls back to the platform default.

### Import much larger player-database backups

The player-database backup import limit has increased from 5 MB to 50 MB. This leaves substantially more room for large deck libraries, owned-card collections, and prompt histories while retaining a practical guard against accidentally importing an unrelated or unreasonably large file.

The backup format remains at schema version 1, so existing backups remain compatible and no migration is required.

## Upgrading from 0.8.1

Install version 0.9.0 over the existing desktop application. Saved decks, owned cards, prompt history, desktop AI settings, provider preferences, and existing database backups remain compatible. The assistant starts in Small on desktop only when no size preference has previously been saved.

Download the package for your platform from the **Assets** section below:

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Attached images must be PNG, JPEG, or WebP files no larger than 10 MB each.
- Player-database backup files remain on backup schema version 1 and can be up to 50 MB.
- The assistant size preference is local to the application or browser and is not part of a player-database backup.
- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.

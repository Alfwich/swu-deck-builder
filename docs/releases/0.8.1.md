# SWU Deck Builder 0.8.1 — Stable mobile footer positioning

SWU Deck Builder 0.8.1 is a focused patch release that keeps the application footer and Deck Assistant controls correctly positioned on compact mobile screens, including Firefox for Android as its dynamic toolbar appears and disappears.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.8.0

### Keep the mobile footer at the visible bottom edge

The compact footer now stays attached to the visible viewport instead of leaving a toolbar-sized gap beneath it. Its links, application version, and fan-project notice remain visible without covering the deck workspace.

Mobile Firefox receives a top-anchored dynamic-viewport layout that avoids the browser's fixed-bottom positioning issue after scrolling or zooming. The layout follows both toolbar expansion and collapse without relying on a device-specific pixel offset.

### Keep the Deck Assistant clear of the footer

The Deck Assistant launcher now follows the same mobile viewport boundary as the footer. It maintains consistent spacing above the footer while the browser toolbar changes size, and the expanded assistant remains reachable and interactive.

## Upgrading from 0.8.0

Install version 0.8.1 over the existing desktop application. Saved decks, owned cards, prompt history, desktop AI settings, and provider preferences are preserved. The player-database backup format remains at schema version 1.

## Get 0.8.1

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.8.1.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.8.1_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.8.1-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

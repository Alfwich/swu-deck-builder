# SWU Deck Builder 0.13.8 — TypeScript and domain architecture

This release completes a major internal refactor of the deck builder. The web
app, server, desktop runtime, scripts, and tests now share a TypeScript-based,
domain-oriented source layout designed to make future changes safer and easier
to maintain. Existing decks, collections, chat history, and settings remain
compatible.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights

- **Migrated the project to TypeScript.** Browser code, the Express server,
  Electron runtime, build scripts, and the complete test suite now use `.ts`
  and `.tsx`, with separate configurations for browser, Node.js, runtime, and
  test environments.
- **Reorganized the application by functional domain.** Web code now lives
  under `src/web` and is grouped into app shell, assistant, catalog, decks,
  integrations, player database, shared utilities, and explicit domain types.
  Server and Electron sources now live alongside it under `src/server` and
  `src/desktop`.
- **Split up the former monolithic `App.jsx`.** Deck workspace, library,
  assistant, catalog, history, import, and application-shell responsibilities
  are now handled by focused components, hooks, and helpers.
- **Separated the stylesheet by domain.** The former single application
  stylesheet is divided into foundation, shell/library, deck workspace, and
  assistant styles without changing the established visual design.
- **Standardized source naming.** TypeScript and TSX files consistently use
  lowercase kebab-case names, enforced by structural tests.
- **Updated build and packaging paths.** Vite, Electron Forge, deployment
  scripts, catalog tooling, and GitHub Actions now compile and package the new
  source tree, with an explicit type-check step in release builds.
- **Made image cleanup deterministic.** Agent chat now removes staged image
  files before completing the HTTP response, fixing a Linux release-test race.
- **Refreshed catalog artifacts.** Obsolete generated catalog data was removed
  and the current deck-builder catalog was packed through the supported tooling.

The domain extraction began in
[4fb5e6c](https://github.com/Alfwich/swu-deck-builder/commit/4fb5e6c63603cbce182fd1167ad9e61ef8950af0),
the TypeScript and source migration landed in
[2ea0301](https://github.com/Alfwich/swu-deck-builder/commit/2ea030159305ceb29da6918317fafe04d01fde0f),
and the Linux cleanup race was corrected in
[f5589d1](https://github.com/Alfwich/swu-deck-builder/commit/f5589d1f26aa6824a3491ebbfa94a1352b1326fc).

See the [full comparison](https://github.com/Alfwich/swu-deck-builder/compare/v0.13.7...v0.13.8) for every changed file.

## Get 0.13.8

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.13.8.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.13.8_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.13.8-1.x86_64.rpm`

Saved decks, owned cards, browser chat state, and desktop settings remain local and are preserved when upgrading.

## Notes

- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.

# SWU Deck Builder 0.8.0 — Adjustable assistant and leaner AI context

SWU Deck Builder 0.8.0 makes the AI deck assistant easier to fit around the workspace, substantially reduces repeated card data sent to AI providers, and brings version and project links into a consistent application footer.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.7.0

### Resize the AI deck assistant

The open assistant panel now has a horizontal resize handle. Drag it to make a compact conversation area or expand it when reviewing longer answers and card-change proposals. The handle also supports the keyboard: use **Up** and **Down** for precise adjustments, or **Home** and **End** to move directly to the minimum or maximum available height.

Panel sizing is constrained to the current viewport, including compact screens, so the assistant remains reachable after a window resize. Its header and controls are also denser, leaving more room for the conversation itself.

### Send less repeated card data to AI providers

AI conversations now retain the most recently transmitted card collection and send the full collection again only when it changes. Failed turns, renewed sessions, and expired continuations safely resend the authoritative snapshot.

Deck and collection card lists use a compact set-grouped tuple representation in model-facing prompts instead of repeating `cardId` and `count` field names for every entry. Representative larger collections are roughly one quarter of their former serialized size. Internal deck and collection data, validation, exact catalog IDs, and structured model responses remain unchanged.

These optimizations apply consistently to the OpenAI Responses API, Codex CLI, and Claude CLI integrations.

### See version, links, and fan-project status consistently

A new footer displays the running application version, GitHub, SWUDB, and TCGplayer links, plus the independent fan-project notice. Moving these links out of the top navigation leaves more room for deck actions and keeps the same information available in the browser and desktop app.

Desktop title-bar spacing and responsive workspace sizing have been adjusted around the new footer. The TCGplayer Mass Entry link now opens with Star Wars: Unlimited preselected.

### Updated project overview

The repository README now includes a current application screenshot showing saved decks, collection ownership, the cost curve, deck cards, and legality information.

## Upgrading from 0.7.0

Install version 0.8.0 over the existing desktop application. Saved decks, owned cards, prompt history, desktop AI settings, and provider preferences are preserved. The player-database backup format remains at schema version 1.

## Get 0.8.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.8.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.8.0_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.8.0-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Attached images must be PNG, JPEG, or WebP files no larger than 10 MB each.
- Database backup files remain on backup schema version 1 and are limited to 5 MB.
- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.

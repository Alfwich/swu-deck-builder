# SWU Deck Builder 0.11.0 — Shared-deck purchase lists

SWU Deck Builder 0.11.0 can prepare one TCGplayer purchase list for every saved deck, accounting for the total number of copies needed across the full deck library instead of treating each deck in isolation.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.10.0

### Purchase cards for every saved deck

The top **Copy TCGplayer list** control now includes an **All decks** toggle. When enabled, draw-deck and sideboard requirements from every saved deck are combined into one alphabetized TCGplayer Mass Entry list. Leaders and bases remain excluded from the purchase payload.

Combine **All decks** with **Missing only** to subtract the card library once from those combined requirements. Equivalent reprints still count as the same gameplay card. If three decks each require three copies of a card and the library contains three copies, the purchase list correctly requests the remaining six.

Leave **All decks** disabled to preserve the existing selected-deck behavior.

### Copy feedback stays current

TCGplayer copy confirmations and warnings now disappear automatically after four seconds. They also clear immediately when the selected deck, saved decks, card library, or either TCGplayer copy option changes, preventing a warning calculated from old settings from remaining on screen.

### Leaner release downloads

Uploaded desktop packages are retained on the three most recently published GitHub releases. Older release pages, version tags, release notes, and GitHub-generated source archives remain available, while their replaceable installer assets are removed.

## Upgrading from 0.10.0

Install version 0.11.0 over the existing desktop application. Saved decks, owned cards, prompt history, assistant preferences, desktop AI settings, provider preferences, and database backups remain compatible. The new TCGplayer options are off by default, so existing copy behavior is unchanged until they are enabled.

## Get 0.11.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.11.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.11.0_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.11.0-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

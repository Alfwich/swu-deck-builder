# SWU Deck Builder 0.7.0 — Faster desktop card ingestion

SWU Deck Builder 0.7.0 expands the Electron deck assistant with persistent prompt history and a multi-image card-ingestion queue, while refining Windows installation branding.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.6.1

### Queue several card images and process them one at a time

The Codex-powered Electron assistant can now accept up to five images at once through the file picker, clipboard paste, or drag and drop from the desktop. Every image is submitted as its own sequential assistant turn, giving each card a distinct response and modification proposal instead of combining a group of cards into one ambiguous request.

The composer shows every queued image with its file size and queue position. Images can be removed before sending, and if processing stops partway through a batch, the unprocessed images remain queued for another attempt.

Image controls remain limited to the Electron app when Codex CLI is the active provider. They stay hidden for Claude and the hosted web service.

### Recall the last 30 assistant prompts

Press **Up** or **Down** in the assistant composer to move through the last 30 submitted prompts, with shell-style restoration of the draft that was present before navigation began. Multiline input keeps normal cursor movement until the caret reaches the first or last line.

Prompt history is stored locally. The Electron app persists it in the same revisioned SQLite player snapshot used for decks and owned cards, so it survives application restarts and temporary loopback-port changes.

### Correct Windows installation branding

Windows Squirrel packages now use the provided SWU icon for the installed-app and uninstall entry as well as the application and setup executable. The corrected icon appears after installing or updating to this release.

## Upgrading from 0.6.1

Install version 0.7.0 over the existing desktop application. Saved decks, owned cards, desktop AI settings, and provider preferences are preserved. The player-database backup format remains at schema version 1.

## Get 0.7.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.7.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.7.0_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.7.0-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Attached images must be PNG, JPEG, or WebP files no larger than 10 MB each.
- Database backup files remain on backup schema version 1 and are limited to 5 MB.
- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.

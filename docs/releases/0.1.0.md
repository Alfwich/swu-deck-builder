# SWU Deck Builder 0.1.0

SWU Deck Builder 0.1.0 is the first public release of a local-first deck builder for *Star Wars: Unlimited*. Browse the card catalog, build and organize decks, check their structure across supported formats, and move lists between SWU Deck Builder and SWUDB—all without creating an account.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights

### Build with the card catalog at your fingertips

- Find cards with fast, typo-tolerant search and see their art, traits, aspects, cost, and available price data.
- Add cards directly to the draw deck or sideboard, choose and replace leaders and bases, and add an optional second leader for Twin Suns.
- Review your deck's cost curve, estimated value, aspect identity, and card counts as you build.
- Sort the draw deck by cost or bring cards from a chosen aspect to the front.

### Keep a local deck library

- Create, rename, switch between, and delete saved decks.
- Start with a sample deck on your first visit, or begin with a blank deck.
- Keep stable deck identities through edits, imports, renames, and AI-assisted changes.
- Store decks in browser storage in the hosted app or in a local SQLite database in the Windows desktop app.

### Check deck structure across formats

Get immediate estimated legality feedback for Premier, Eternal, Trilogy, Sealed, Draft, and Twin Suns. The builder checks deck size, leader and base structure, copy limits, sideboard size, aspects, and other rules it can determine from the local catalog.

Format rotation, suspensions, set-release eligibility, and other time-sensitive policy decisions may still require confirmation against the latest official rules.

### Import, export, and play elsewhere

- Import SWUDB-compatible JSON, including JSON copied from a fenced code block.
- Copy any export-ready deck as SWUDB-compatible JSON.
- Take exported decks to SWUDB or a compatible tool, including [ForceTable](https://www.forcetable.net/) for playtesting.

### Optional AI Deck Assistant

The Deck Assistant can build a new deck, answer deck-building questions, or propose changes to the selected deck. Every proposed addition, removal, and replacement is reviewable, and nothing changes until you accept it. Card references in the conversation open visual previews, and supported browsers can use dictation for prompts.

The Windows app can connect to an authenticated Codex or Claude CLI from Desktop settings, with controls for provider, model, reasoning effort, executable path, and web search. Server operators can also configure an OpenAI API provider. AI access is optional and disabled when no provider is configured.

## Get 0.1.0

### Use it in a browser

Visit [swu.wuteri.ch](https://swu.wuteri.ch/). Your decks and recent Deck Assistant conversation stay in that browser profile.

### Install the Windows app

Download the `.exe` installer from the **Assets** section below and run it. Decks and desktop settings are stored in your Windows user-data directory, outside the installed application, so application updates do not replace them.

The 0.1.0 desktop release is Windows-first. Builds may be unsigned, so Windows can display a reputation or publisher warning during installation.

### Run from source

Node.js 22 or later is required.

```powershell
git clone https://github.com/Alfwich/swu-deck-builder.git
cd swu-deck-builder
npm install
npm run dev
```

The app opens at `http://127.0.0.1:5173`. If a usable catalog is not already present, startup downloads and caches the public catalog automatically.

## Notes for this first release

# SWU Deck Builder 0.5.0 — Portable backups and cleaner desktop workflows

SWU Deck Builder 0.5.0 adds portable player-database backups, corrects TCGplayer Mass Entry exports, and gives the Electron app a more integrated window layout.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## What's new since 0.4.0

### Export and restore the player database

A new **Database** group appears at the left of the top menu. **Export** downloads a dated, versioned JSON backup containing every saved deck, the selected deck, and the complete card collection. The backup uses catalog card IDs instead of copying artwork URLs or provider data, keeping it compact and portable.

**Import** validates the backup format, version, deck records, card types, quantities, timestamps, and every referenced card against the current catalog. A summary shows the file date, deck count, and collection size before anything is changed. Restoring requires explicit confirmation and then replaces the current decks and collection. AI provider settings, credentials, and chat history are intentionally excluded.

The same flow works with browser-local persistence and the SQLite-backed Electron deck library, making it useful both for routine backups and for moving player data between installations.

### TCGplayer Mass Entry compatibility

TCGplayer exports now use the accepted `quantity Card Name - Subtitle [SET]` format. Collector numbers are no longer appended after the set code, and the list is sorted alphabetically for easier review.

The purchase list now contains only draw-deck and sideboard cards. Leaders and bases are excluded, matching TCGplayer's expected deck-purchase payload. The **Missing only** option applies the same rules while subtracting owned equivalent printings from the card collection.

### A more integrated Electron window

The Electron app now hides the native title bar and preserves the operating system's standard window controls as an overlay. The application header acts as the draggable window region, while its buttons and links remain fully interactive.

The top menu has also been tightened so Database actions sit immediately to the left of Deck actions. Compact labels and horizontal overflow handling keep the controls usable across narrower layouts without wrapping the navigation into the workspace.

## Upgrading from 0.4.0

Install version 0.5.0 over the existing desktop application. Saved decks, the card collection, desktop AI settings, and provider preferences are preserved. After upgrading, use **Database → Export** to create a portable backup whenever you want an additional recovery copy.

## Get 0.5.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.5.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.5.0_amd64.deb`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

## Notes

- Database backup files are limited to 5 MB and currently use backup schema version 1.
- Restoring a backup replaces the current deck library and card collection after confirmation.
- Windows and Linux packages currently target x64 systems.
- The macOS package is universal and supports both Apple Silicon and Intel Macs.
- Windows and macOS builds may not yet be code-signed, and macOS builds may not be notarized. Your operating system can display a publisher or trust warning during installation or first launch.
- Image attachments remain limited to the Codex provider in the Electron app.
- Codex and Claude integrations use the account authenticated in the selected CLI and may consume that account's subscription allowance.
- This independent fan project is not affiliated with or endorsed by Lucasfilm Ltd., Fantasy Flight Games, TCGplayer, or SWUDB.

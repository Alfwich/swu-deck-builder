# SWU Deck Builder 0.10.0 — Consistent deck layouts

SWU Deck Builder 0.10.0 makes card layouts deterministic, so decks containing the same cards display those cards in the same order regardless of how they were created, imported, or edited.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.9.1

### Identical decks now share the same layout

Card rendering no longer falls back to the order in which cards happened to appear in the underlying deck data. When no cost or aspect sort is selected, draw-deck cards are arranged alphabetically by name.

When a cost direction or priority aspect is selected, those choices remain the higher sorting precedence. Card name, subtitle, and stable card identity now provide deterministic tie-breakers afterward. This preserves the existing sorting controls while ensuring equivalent decks converge on the same visual layout.

### Deterministic sideboards

Sideboard card groups now use the same alphabetical identity ordering instead of retaining import or insertion order. Reopening, importing, or independently constructing an equivalent deck therefore produces a consistent layout in both the draw deck and sideboard.

## Upgrading from 0.9.1

Install version 0.10.0 over the existing desktop application. Saved deck data is not reordered or migrated; the consistent ordering is applied only when cards are displayed. Saved decks, owned cards, prompt history, assistant preferences, desktop AI settings, provider preferences, and database backups remain compatible.

- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.

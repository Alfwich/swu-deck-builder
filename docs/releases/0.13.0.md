# SWU Deck Builder 0.13.0 — Safer releases and assistant sizing

SWU Deck Builder 0.13.0 keeps the deck assistant clear of the site navigation on every viewport and introduces safer, repeatable automation for preparing and publishing releases.

[Open the hosted app](https://swu.wuteri.ch/) · [View the project on GitHub](https://github.com/Alfwich/swu-deck-builder)

## Highlights since 0.12.0

### Assistant sizing respects the site navigation

The deck assistant now measures the site navigation and keeps a small gap beneath it. Its height is clamped against that boundary when the panel opens, the browser window changes size, or the panel is resized with a pointer or keyboard.

The existing **Small** and **Large** choices remain available, and manual resizing continues to preserve the selected size preference.

### Nightly releases only when changes are ready

A scheduled workflow now checks the default branch each night. When no commits have landed since the latest stable release, it exits without creating a release. When changes are available, it runs the test suite, lint checks, and browser build before preparing the next patch version, release notes, commit, and tag.

The preparation step is covered by focused tests and can safely resume an unpublished prepared release instead of producing duplicate release commits or tags.

### More reliable cross-platform publishing

Release publishing now validates that the requested tag, package metadata, and release notes agree before building. Windows, macOS, and Linux jobs all build the exact tagged revision, and publishing can safely retry a stale draft without replacing an already published release.

Uploaded installer assets from version 0.11.0 and older are removed after this release. Their release pages, tags, notes, and GitHub-generated source archives remain available.

### Cleaner project organization

The browser entry point now lives with the application source, while temporary local attachment files stay outside version control. Build and development commands continue to work as before.

## Upgrading from 0.12.0

Install version 0.13.0 over the existing desktop application. Saved decks, owned cards, prompt history, assistant size preferences, desktop AI settings, provider preferences, and database backups remain compatible.

No deck or collection migration is required.

## Get 0.13.0

Download the package for your platform from the **Assets** section below:

- **Windows x64:** `SWU.Deck.Builder-0.13.0.Setup.exe`
- **macOS, Apple Silicon or Intel:** `SWU.Deck.Builder.dmg`; use the universal `.zip` if you prefer an archive
- **Debian or Ubuntu Linux x64:** `swu-deck-builder_0.13.0_amd64.deb`
- **Fedora or RHEL Linux x64:** `swu-deck-builder-0.13.0-1.x86_64.rpm`

Prefer the browser? The latest hosted version remains available at [swu.wuteri.ch](https://swu.wuteri.ch/), with no installation required.
